## Description

EmporiUm is a student bookstore chain that sells technology, art supplies, and other merchandise both in-store and online. This project analyzes sales performance, identifies revenue trends, compares results to other regions, and recommends areas of focus for the next quarter.

## Project Objectives
By using SQL and sales data from EmporiUm, this project answers professional questions about South Carolina's sales, evaluates revenue and trends, compares performance to other regions, and provides new recommendations. The analysis evaluates revenue trends, compares territory performance to regional results, and communicates findings through data visualizations, including a Pivot Chart.

**Territory**

- Region: South
- State: South Carolina
